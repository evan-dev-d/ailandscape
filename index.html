01
第 1 节 · 基础概念约 2 分钟

先认识 6 个词

不懂 AI 也没关系。这六个词是整张地图的图例；先记住它们，再看下面的关系图和造车动画。

🧠

大模型 LLM

AI 的大脑：读过海量文字，会写、会算、能看图。它是发动机，但需要产品才能用起来。

⚡

算力 Compute

AI 的「电」：训练和运行大模型都要消耗 GPU 算力；算力越多，模型越大、回答越快。

🪙

Token 词元

AI 的计费单位：文字会被切成小块，一块约 0.5–1 个汉字；你输入的、它输出的都按 Token 算。

🤖

智能体 Agent

给大脑装上手脚：你给目标，它自己拆任务、用工具、操作电脑，跑完整流程。

⌨️

编程智能体

在终端或 IDE 里替你读代码、改代码、跑测试。代表：Claude Code、Codex、Trae。

🧑‍💼

办公智能体

替你做资料、表格、PPT、邮件。代表：WorkBuddy、Kimi Work、M365 Copilot。

大模型训练与推理，要消耗下面两样 ↓
⚡ 算力

GPU / 数据中心，大模型的「电」。训练和每次生成回答都要消耗算力。

🪙 Token

大模型读写文字的最小单位（约 0.5–1 个汉字），输入输出都按 Token 计费。

一句话记住：模型公司是造车厂，算力是电，大模型是发动机，Token 是油耗，智能体是整车，你只要说目的地。

换个比喻：AI 像一条造车流水线
车企 → 工厂和电 → 车系 → 车型 → 加油 → 自动驾驶出租车
1
模型公司 = 车企研发、生产、销售模型，像奔驰 / 比亚迪
2
算力 = 工厂和电训练模型要烧算力，运行模型也要
3
大模型 = 车系 / 平台能力底座，比如 GPT、Claude、Qwen
4
具体模型 = 具体车型同一车系的不同配置 / 年份，比如 Opus 5.5、Sonnet 5.5
5
Token = 油跑多少烧多少，按用量计费
6
智能体 = 自动驾驶出租车车 + 自动驾驶 + 接单系统，自己把活干完；你 = 乘客，只要说目的地

比喻只为帮助理解、不完全精确：算力是「造车工厂 + 发电」，Token 是「油表上的升数」；真实 AI 里它们一个是资源、一个是计费单位。

第 3 节 · 工具选择约 2 分钟

按需求挑一个工具

先想清楚你要干什么：写代码、做办公，还是自己部署。点名字直接打开官方入口。

⌨️想写代码

编程智能体：在终端 / IDE 里直接改你的项目。

🧑‍💼想办公提效

白领智能体：查资料、做表、写报告、回邮件。

🔓想开源 / 自己部署

开放权重模型：可下载、可私有化、成本更可控。

提示：海外产品通常用邮箱注册，部分可能需要外币卡或特定网络环境；不确定就先试免费版。只想选模型的话：T1 前 8 名综合最强；想便宜大碗，优先看名字带 Flash 的型号（DeepSeek V4.1 Flash、GLM-5.3 Flash、MiniMax M3.1 Flash）。

第 4 节 · 上手使用约 1 分钟

注册与下载：3 条小提示

选好之后，回到排行榜点「注册体验」或「下载 App」即可。下面是三条上手提示。

国内产品

手机号就能注册

多数支持手机号 / 微信登录，注册后一般有免费额度，先试用再决定。

海外产品

邮箱注册，按需选择

通常用邮箱注册；部分服务需要外币卡或特定网络环境，先用免费版试试。

编程智能体

先装工具再登录

CLI 或 IDE 插件装好后用账号登录；办公智能体一般直接网页端就能用。
